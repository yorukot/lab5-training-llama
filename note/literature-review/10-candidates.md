## D. 不建議（有證據）
- **損失形式：** 換成 reverse KL、skew KL、TVD、AKL、MSE 或 cosine 都不建議
  - 預訓練、看 LM loss 時，forward KL 一致最好：Busbridge 的 RKL 差 0.28 nats；Minitron
- **tail 的分配方式：**
  - tail 均勻分配：比不蒸餾還差（SLS）
  - tail 依學生分配（ghost）：比現在差
  - top-32 重新正規化：Busbridge 測到 +0.11 nats
- **α 的其他做法：**
  - 丟掉 token（Rho-1、ATKD）：OJ 評全部 token
  - α 從 0 暖身：跟我們 CI 的數據相反
  - 最後把 α 降到 0：CD 已顯示 α 0.5 明顯差
  - 依老師熵或學生差距給每個位置不同的 α（T1b C4/C5）：預訓練加 ppl 的條件下沒有正面證據
- **排程與權重平均：**
  - 衰減段的權重平均：學到 0 時收益 ≤0.12%，150M 也輸了
  - schedule-free
  - 長衰減配 1-sqrt：待辦清單的「20% 1-sqrt」建議移除
  - γ 改成以整段比例計
- **批次：**
  - 6B 改 262k
  - 批次漸增：步數省 9%，但 ppl 頂多打平，又要改 Trainer
- **優化器：**
  - 跟 EMA-Nesterov 重疊的：AdEMAMix、SODA、外層 Nesterov
  - Muon 變體：AdaMuon、NAMO、OLion、DeVA、HTMuon、MARS、Muon 上的 cautious 遮罩
  - Shampoo、PSGD-Kron、完整 SOAP
  - embedding 改用 Muon 或 sign
  - Hyperball 一類的範數限制
- **精度與量化：** 最後一段改純 bf16 forward、更好的 bf16 捨入、z-loss 都不建議。bf16 只佔 1.2% 差距的約一成，預期 ≤0.1%
- **截止前不做、之後可做：** Muon-VS、DynMuon（先在 150M 篩）、FP8
- **資料與盲點（T6）：**
  - 依品質或難度的課程：lr 衰減到 0 時失效，eval 又是同分布
  - MTP 輔助頭：1.3B 的 BPB 從 1.08 變差到 1.12
  - TOP 輔助頭（ICML 2026）：收益 −1.7%，但計算多約 20%，6B 會超過 64 h
  - 調 grad clip、AdamW eps、z-loss：預期約 0
  - Coupled Adam、input 端梯度放大：有反證
- **T6 對 K1 的提醒：** T6 從 CI 和 CH 的差距推估，真實的 tail 偏差只有理想值的約 1/20，所以 K1 的收益可能偏小
