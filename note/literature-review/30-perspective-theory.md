## 1. K1：無偏 tail target

### 1.1 推導（獨立重做）
- **記號：**
  - S：老師的 top-32
  - m = Σ_S p_T
  - y：資料答案
  - P_out = P(y∉S | x)
  - c(y)：答案拿到的份額
- **現在的 target（V0）：** q = α·p_T|S + (1−αm)·e_y，Σq = 1
  - top-32 內的期望值：α·p_T + (1−αm)·p_data
  - tail 的期望值：(1−αm)·p_data
  - 若 p_T = p_data：top-32 被放大 1+α(1−m) 倍，tail 被縮小 1−αm 倍（α 0.8、m 0.9 時是 0.28 倍，跟 T1a、T6 一致）
- **K1（V1）：** q = α·p_T|S + c(y)·e_y，其中 c(y) = 1−α + α·1[y∉S]
  - top-32 內的期望值：α·p_T + (1−α)·p_data
  - tail 的期望值：(1−α+α)·p_data = p_data
  - 正規化常數：E[Σq | x] = Z(x) = 1 − α(1 − m − P_out)
    - 平均 E[1−m] = 9%、P_out = 7%，所以 Z ≈ 1 − 0.02α
  - softmax 學生在期望 loss 下的最佳解是 E[q]/Z(x)
  - 所以「tail 跟資料一致」不需要任何條件；「老師在 top-32 校準」（m = 1−P_out）只影響 Z 是不是剛好等於 1
    - T1a 把這個條件寫成無偏的前提，說法稍微不精確，但結論對
- **梯度：** ∂(−Σ q_i log softmax_i)/∂z_k = (Σq)·softmax_k − q_k
  - V0 因為 Σq = 1 才能寫成 softmax − q；K1 必須乘上 Σq
  - 梯度在詞表上的總和仍是 0，所以不會推動 logits 的平均值
- **數值驗證（`k1_abc.py` 第 A 部分，float64，V=500，64 個位置）：**
  - T1a 草圖的 loss 和梯度，跟 autograd 對 dense target 的結果差 < 1e-16
  - 拿掉 `mul_(total)` 時差 4e-2，所以這個因子必要，而且草圖已經有
- **草圖的小細節：**
  - `alpha * tail` 是 bool 乘 float，結果是預設的 float32
    - 實際程式的 `kd_probs` 是 float32，不會出錯
    - 用 float64 測試時要先轉型，否則 `scatter_add_` 會報 dtype 錯誤（我實際遇到）
  - 快取缺失的位置（ids 全 0、probs 全 0）：K1 給 data = 1，等於 CE，跟 V0 一樣，正確
  - T1a 寫「Σq 落在 0.8–1.8」只是典型值
    - 界限是 [1−α+αm, 1+αm]
    - 老師不確定（m 小）而答案剛好在 top-32 內時，Σq 可以低到 0.3–0.5

### 1.2 變異數：K1 的主要代價
- 每個位置對 logits 梯度的標籤雜訊 E‖g − E g‖²（學生 = 真實分布時算，`k1_abc.py` 第 C 部分）：

| α | CE | V0 | V1（K1） | V1 / V0 |
|---|---|---|---|---|
| 0.8 | 0.718 | 0.073（CE 的 10%） | 0.143（CE 的 20%） | 1.97 |
| 0.9 | 0.718 | 0.042（CE 的 6%） | 0.125（CE 的 17%） | 2.95 |

- **解讀：**
  - K1 在 α 0.9 時的標籤雜訊，大約等於 V0 在 α ≈ 0.65 的水準
  - 換句話說，K1 把 KD 的變異數縮減吐回一部分
  - 依 variance-reduction 理論（第 2 節），雜訊代價跟 lr 成正比，偏差代價不隨 lr 變
  - 因此 **K1 的淨收益應該在 stable 段最小（甚至為負），在衰減段最大**
  - T1a 的 1B 測試設計（看收益是否集中在後段）是對的判準
- **跟批次的關係：** K1 讓梯度雜訊變大，等於把 critical batch 往上推一點。AT/AU 顯示我們在批次偏小那一側，影響應該是二階的

### 1.3 Σq ≠ 1 的其他影響
- **loss 尺度：**
  - 訓練 log 的 loss 是 −Σ q log p，不是 CE，不能跟 V0 的 run 直接比
  - eval 不受影響
- **lr 等效：**
  - Muon（正交化）和 AdamW（逐元素正規化）對梯度的整體尺度不敏感
  - 平均 Σq ≈ 0.98，所以不需要調 lr
  - 真正改變的是「各位置的相對權重」：答案在 tail 的位置（難 token）權重變成 1+αm，在 top-32 內的變成 1−α+αm
  - 方向跟 SLS Table 10 的「hard token 加權」一致
- **grad clip 1.0：** 梯度範數略增，clip 可能多觸發幾次；對 Muon 沒影響，對 AdamW 幾乎沒影響
- **NorMuon：** 它只正規化正交化後更新的每一列，跟位置的權重無關，沒有交互
- **EMA-Nesterov：** 沒有交互
- **α：** K1 拿掉偏差項後，最佳 α 應該往上移（見第 2 節）
  - 6B 若採用 K1，α 不應再降到 0.8 以下，0.85–0.9 更合理

### 1.4 實現比例：T1a 的 15–20% 與 T6 的 1/20，哪個合理
- **T6 的推法：** 觀測到的 CI − CH（0.26%）除以「理想的 α 1.0 與 0.9 差距」
  - **算術錯誤：** T6 用的「理想差約 6%」，是它自己玩具裡 α 1.0 減 α 0.8（0.095 − 0.034 = 0.061 nats）
  - 我重跑 T6 的玩具：α 0.9 是 0.0546 nats，α 1.0 − 0.9 的理想差是 0.042 nats（4.3%）；T1a 的玩具是 0.043
  - 修正後比例約 1/16
  - **方法本身有混淆：** CI − CH 是「α 1.0 減 α 0.9」的總效果，除了 tail 偏差，還包括：
    - (a) 少了 head 裡的資料訊號，老師在 head 的誤差會被完整吸收
    - (b) 標籤雜訊更低：CI 在 5–10% 領先 0.3–0.56%，證明這一項是正的而且不小
  - 所以「偏差代價 = 觀測差距 + 雜訊好處 − 老師 head 誤差」，無法用一個差距辨識出來
  - 1/20 只在「α 0.9 → 1.0 除了 tail 之外什麼都沒變」時才成立，而 CI 的前期領先正好反駁這個假設
- **T1a 的推法：**
  - SLS 在同一個 α（=1）下只換 tail 的處理（Naive Fix vs FullKD），差 0.012–0.019 nats
  - 再除以玩具的理想值（0.09–0.12）
  - 這是「只改 tail」的對照，辨識性好得多；缺點是分母來自玩具，不是 SLS 的老師
- **我的兩個獨立檢查：**
  1. **容量受限的學生（`k1_d.py`）：**
     - 設定：學生的 logits = log p + σ·雜訊（雜訊代表學生不知道的東西）
     - 學生只能學兩個全域旋鈕：溫度，以及自己 top-32 的整體加成。這兩個都是網路很容易學到的方向（最終 norm 的尺度、整體銳化）
     - 結果：

       | 學生離真實的距離（excess） | α 0.8 | α 0.9 | α 1.0 |
       |---|---|---|---|
       | 約 0.09 nats | 73% | 67% | 56% |
       | 約 0.33 nats | 54% | 49% | 39% |
       | 約 0.73 nats（最接近 1B） | 36% | 32% | 25% |
       | 約 1.2 nats | 22% | 18% | 16% |

     - 1B 學生（ppl 15.3）對 8B 老師的距離大約 0.6–0.7 nats，對應實現 **約 30%**
     - 學生越強，實現的比例越高，所以 6B 的實現比例會比 1B 高
     - 在 α=1、excess 0.33–0.73 時，實現量是 0.027–0.042 nats，跟 SLS 實測的 0.012–0.019 同數量級（約 2 倍）
  2. **從 α 掃描反推（`alpha_fit.py`）：**
     - 模型：觀測 = −G(α) + f·B(α)
       - G 是單調飽和的毛收益（試了三種形式）
       - B 是理想偏差
     - 最佳的 f 是 0.25–0.35；f = 0.05 的擬合誤差是 f ≈ 0.3 的 2–3 倍
     - 但三參數擬合四個點，殘差（0.13%）仍遠大於雜訊。如果老師的 head 誤差讓 G 本身在 α<1 就達到最高，f 就無法辨識
- **結論：**
  - T1a 的 15–20% 比 T6 的 1/20 合理，因為辨識方式乾淨
  - 真實值可能落在 15–35%
  - 以 α 0.9 的理想偏差 0.055–0.068 nats 計，**毛收益約 0.8–2%**
  - 扣掉第 1.2 節的雜訊代價（無法估算，但不是 0），T1a 的「−0.5%（−0.2 到 −1.5）」是合理的中心值
  - T6 的「K1 收益可能偏小」這個提醒，根據的是混淆的推論，不應該用來降低 K1 的優先度

### 1.5 判決
- **機制：成立**
- **先做 1B 測試**
  - 設定：CJ 加 K1，同 seed
  - 判準：≤ −0.3% 才採用；收益應該在衰減段擴大
  - 若 stable 段落後、衰減段反超，就是第 1.2 節「雜訊 vs 偏差」的特徵，代表機制正確
- **不可以未經測試直接用在 6B：** 變異數代價的符號和大小都沒有證據
- **6B 的轉移：**
  - 學生越強，實現比例越高；但 6B 的 α 0.8 讓理想偏差變小（0.046 vs 0.068），兩者大致抵銷，預期跟 1B 差不多
  - 若 6B 改回 α 0.85–0.9，收益會略大

## 2. K3：α 跟 lr 連動

### 2.1 論文的結論是什麼（Safaryan et al. 2023，p.6–7）
- **前提：** SGD 的 self-distillation：x ← x − γ(∇f_ξ(x) − λ∇f_ξ(θ))
  - 這個式子跟我們的 target 是同一件事
  - 對 logits 的梯度 = (p_S − e_y) − α(p_T − e_y)
  - 也就是老師在同一個樣本上的梯度當作 control variate，λ = α
- **收斂鄰域：** N(λ) = λ²‖∇f(θ)‖² + γ·E‖∇f_ξ(x*) − λ∇f_ξ(θ)‖²
  - 第一項是老師偏差造成的固定點偏移，跟步長無關
  - 第二項是雜訊，乘上步長 γ
- **最佳權重：** λ* = E⟨∇f_ξ(x*), ∇f_ξ(θ)⟩ / (E‖∇f_ξ(θ)‖² + ‖∇f(θ)‖²/γ)
  - 當 γ → 0，λ* ∝ γ → 0
  - **論文的結論是 λ* 會一路降到 0，不是停在 0.7**
- **適用範圍：** 強擬凸或 PL、靠近最佳點；實驗是 MNIST 的線性模型

### 2.2 在 Muon（更新 RMS 固定）下是否還成立
- **偏差項：**
  - 正交化是奇函數；雜訊對稱時，E[msign(μ+n)] 在 μ=0 時為 0
  - 所以固定點仍然是「target 期望梯度 = 0」的地方
  - 偏差造成的固定點偏移跟 lr 無關，這點跟 SGD 一樣
- **雜訊項：**
  - Muon 每步位移固定為 lr × RMS 0.2，雜訊只降低「朝向訊號的比例」（回復力約 ∝ 訊號/雜訊）
  - 穩態的震盪帶寬約 ∝ lr，而且對雜訊大小是一次方，不是 SGD 的平方
  - 所以「雜訊代價 ∝ lr、偏差代價與 lr 無關」的結構還在，**「lr 越小，α* 越小」在定性上成立**
  - 因為 Muon 的步長固定、不會因為雜訊變小而自己縮小，所以 Muon 下這個論證甚至比 SGD 更乾淨
  - AdamW 組在雜訊主導時，m/√v 會自己縮小，結構相同但較弱
- **定量形式不轉移：**
  - λ* 的式子是 SGD 加上靠近最佳點的條件
  - 我們在 5 TPP，大部分時間離收斂很遠，老師在 stable 段的價值主要是「資訊」，不是「降雜訊」
  - 所以理論只能解釋衰減段的行為
- **結論：** T1b 的「α_end 0.7、跟 lr 線性連動」是經驗式，不是理論推出的形狀

### 2.3 跟 K1 的關係
- **偏差項有兩個來源：**
  - (a) 老師在 head 的誤差
  - (b) V0 的 top-32 tail 偏差
- K1 拿掉 (b)，所以 K1 之後：
  - λ* 整體上移（C3）
  - λ* 隨 lr 下降的幅度變小
- 我們看到「CI 衰減段輸給 CH」，K1 和 K3 都能解釋，資料分不出是哪一個
- 這是 F 節第 2 題的核心：兩個改動要一起設計

### 2.4 判決
- **機制：部分成立**
- **先做 1B 測試**，跟 K1 做 2×2：CJ、K1、K3、K1+K3
  - 如果只有兩個位置：K1 和 K1+K3，因為 6B 要的是「有 K1 時 K3 還有沒有用」
- **D 節的錯誤推理：**
  - 「最後把 α 降到 0：CD 已顯示 α 0.5 明顯差」這句不成立
  - CD 是整段固定 0.5，對「只在最後 lr 很小時降 α」沒有任何資訊
  - 理論反而預測 α* → 0
  - 結論（截止前不做）可以保留，因為最後幾 % 的步長很小、影響有限；但理由要改

## 3. K4：τ 隨 tokens 變小

### 3.1 EMA 觀點下的機制
- **權重是更新的 EMA：**
  - 解耦式 wd 下，θ_T = Σ_s η_s·Π_{r>s}(1−η_rλ)·(−u_s) + Π(1−η_rλ)·θ_0
  - 權重是過去更新的 EMA，時間常數 1/(ηλ) 步；τ 是它占整段的比例
  - 這個結構對任何更新規則都成立（AdamW、Muon、NorMuon），只要 wd 是解耦、乘法式的
- **τ 在取捨什麼：**
  - (a) 遺忘：忘掉初始化和早期（模型還很差時）的更新
  - (b) 平均：平均掉雜訊
- **為什麼 τ 應該隨 tokens 變小：**
  - 雜訊每步的大小固定時，平均需要的「步數」不隨訓練長度增加
  - 但「整段比例」固定（τ 固定）代表窗口步數 ∝ 總步數
  - 窗口太長，就會把早期較差的更新留太多
  - 對一個「目標在漂移、觀測有雜訊」的追蹤問題，最佳窗口步數隨總步數的成長通常是次線性，換成比例就是 τ ∝ S^(−b)，0 < b < 1
  - Power Lines 的 b ≈ 0.53 等於「窗口步數 ∝ √S」，正好在兩個極端中間
- **τ 固定（Wang & Aitchison）在什麼情況下成立：**
  - 多 epoch 時，「目標」大致不動，每個 epoch 的資訊量相同，用固定比例平均是自然的
  - 單趟訓練裡，資料每次都是新的，模型在進步，舊更新的價值會下降
  - 所以 τ 固定在單趟訓練缺少機制依據
- **衰減到 0 時：** lr → 0 讓窗口步數變長（1/(η_tλ) → ∞），雜訊平均主要靠排程完成；wd 的角色剩下遺忘和平衡範數
  - 這也解釋了 AN 的軌跡：τ 短的那支在 stable 段落後（85% 時 20.66 vs 20.16），衰減後反超
  - 所以 τ 的收益在衰減段才兌現，**中途的比較（例如 CM 在 85% 的比值）不能拿來判斷 τ**

### 3.2 Power Lines 的形式能不能用在 Muon / NorMuon
- **形式可以用：**
  - EMA 時間常數只看 ηλ，跟更新規則無關
  - Moonlight 把更新 RMS 對齊到 0.2，所以同樣的 η、λ 下，平衡時的權重範數跟 AdamW 同一個數量級
  - τ 的數值有可比性
- **前面的係數不同：**
  - Muon 的更新大小不隨訊噪比縮小，雜訊主導時「每步相對太大」，更依賴 τ 和排程來壓雜訊
  - 這解釋了 T3a 觀察到的「Muon 的 τ_opt 比 AdamW 低 2–3 倍」
- **指數 b 沒有直接量測：**
  - Muon 兩點連線 −0.33
  - HyperP 換算 −0.36
  - Fantastic 的粗格點 −0.97
  - b 落在 0.3–1 都有可能
- **NorMuon 的交互：**
  - AH/AJ/AM：wd 越大，NorMuon 的收益越小（−1.7% → −1.35% → −0.76%），表示兩者部分重疊
  - 6B 的 wd 變大時，NorMuon 的收益會再縮一些，抵銷一部分 τ 的收益
  - 這會讓最佳 τ 略往長的方向移

### 3.3 新發現：EMA-Nesterov 會縮短等效 τ（T3a 說「影響很小」是錯的）
- **來源：**
  - `optimizer.py` 把 wd 項放進 EMA-Nesterov 的 step：step = −lr·(update + wd·p)
  - −lr·wd·p 是很慢、持續的分量，在穩態會被放大 1/(1−β) 倍，跟訊號一樣
  - 也就是說，在窗口內，等效的 lr·wd 也被放大
- **模擬（`ema_sim.py`，真實排程：1% warmup、最後 80% 線性衰減、β = 0.6·lr 比例）：**

| 設定 | wd 的總收縮（e-fold） | 沒有 EMA 時 | 倍數 | 等效 τ（名目 0.39） |
|---|---|---|---|---|
| 1B，窗口 15–74% | 2.60 | 1.53 | ×1.70 | 0.23 |
| 1B，窗口 5–74%（K7） | 3.10 | 1.53 | ×2.03 | 0.19 |
| 6B，窗口 15–74% | 2.50 | 1.53 | ×1.64 | 0.24 |
| 6B，窗口 5–74%（K7） | 2.90 | 1.53 | ×1.90 | 0.205 |

- **這對 K4 的意義：**
  - 1B 的 τ 掃描（AI/AK/AL/AN）沒有 EMA-Nesterov，而且是 50% 衰減：
    - 平均 lr 比例 0.725
    - 擬合的最佳 0.34 相當於 2.13 e-fold
    - AN（0.27）相當於 2.69 e-fold
  - 現在的配方（τ 0.39、80% 衰減、EMA）在 1B 是 2.60 e-fold，已經在 1B 掃描的最佳點附近，甚至略短一側
  - T3a §4.2 把 1B 最佳換算成「80% 衰減下 0.28」，沒有算 EMA；算進去後，**現行配方下 1B 的名目最佳 τ 約 0.39–0.48**
  - 窗口照比例縮放，1B 和 6B 的放大倍數幾乎一樣（1.70 vs 1.64），所以「τ_6B = τ_1B × 6^(−b)」的比例論證不受影響；只是基準要用 0.39–0.48，不是 0.28
  - 換算 6B：
    - b = 0.36：0.21–0.25
    - b = 0.53：0.15–0.19
    - b = 0.2：0.27–0.33
  - **0.2 大約對應 b ≈ 0.45，比 T3a 自己認為的稍微激進**
- **跟 K7 疊加：**
  - K7（5% 開啟）會在 6B 再多 ×1.16 的收縮
  - K4 加 K7 一起用時，等效 τ 會比 K4 單獨用再短 14%
  - 兩者不應該未經測試就疊加；若都採用，名目 τ 要乘 1.16（例如 0.2 → 0.23）
- **副產品：** EMA-Nesterov 的「開啟時跳升、之後追回」，有一部分可能就是「τ 變短」的效果
  - AN 的模式也是 stable 段變差、衰減後變好
  - CG（γ 0.997）沒有跳升也少了收益，跟這個解讀相容

### 3.4 1B 時 τ 在 0.27–0.55 很平，對 6B 的意義
- **兩側的斜率差很多：**
  - 長的一側很陡：1.09 → 0.55，每倍 −2.0%（plain Muon）；用 NorMuon 的資料扣掉後約 −1.4%
  - 短的一側很平：0.55 → 0.27，每倍 −0.32%，而且還在改善
  - 拋物線擬合把最佳點放在 0.34，但這條曲線明顯不對稱：長的一側像指數牆、短的一側平
  - 所以真實最佳點可能 ≤ 0.34，拋物線會高估短側的懲罰（T3a 也提到）
- **決策上的意義是風險不對稱：**
  - 若 6B 的最佳點往左移 b·log2(6) ≈ 0.9–1.4 倍頻（b = 0.36–0.53），τ 0.39 會落在陡的那側約 1 倍頻，依 1B 斜率懲罰約 1%
  - 若最佳點不動（b = 0），選 0.2–0.25 是在平的那側往左 0.6–1 倍頻，依 AN 的斜率懲罰約 0.1–0.3%
  - 期望遺憾支持往短的方向移
- **另外：** 1B 的平坦本身說明「在 1B 測不出 τ 的最佳點」，所以 3B 的 E1 才有資訊量

### 3.5 判決
- **機制：部分成立**
  - 方向（τ 隨 tokens 變小）在單趟訓練下有機制依據，τ 固定則沒有
  - 幅度 b 不確定（0.3–1）
- **最好用 3B 測**：E1，CL 只改 τ → 0.22，對照 CL
- **沒有 3B 的話：** 6B 用 0.22–0.25，不要用 0.2 以下
  - 依據是第 3.3 節的 EMA 修正，加上第 3.4 節的不對稱風險
- **跟 K7 不要同時未經測試就改**

## 4. K8、K9：AdamW 組（tied embedding 與 norm）

### 4.1 K8：較短的衰減
- **機制本身：**
  - AdamW 的 m/√v 在雜訊主導時會自己縮小
    - β1 0.9 時，純雜訊的更新 RMS 約 √((1−β1)/(1+β1)) ≈ 0.23，有訊號時接近 1
    - 等於自帶最多約 4 倍的退火
  - Muon 的更新 RMS 固定，只能靠排程退火
  - 所以 AdamW 組比較不需要長衰減。這是逐元素的性質，tied 不會破壞它
- **tied 帶來的削弱，有三點：**
  1. **KD 削弱了自我退火的前提：**
     - tied embedding 的梯度大部分來自輸出端（softmax 對所有列都有梯度，密集）
     - KD α 0.9 讓輸出端的標籤雜訊只剩 CE 的約 6%（第 1.2 節）
     - 梯度變成訊號主導後，AdamW 的自我退火變弱，它對長衰減的需求更像 Muon
     - Track 3 #24 沒有 KD，所以它的 −1.6% 不能直接搬過來
  2. **K8 不只是「晚一點衰減」：**
     - EMA-Nesterov 的 β 用每組自己的 lr 比例算，embedding 的 β 會在 0.6 停到 60%
     - wd 的總收縮也多 ×1.34（平均 lr 比例從 0.595 變 0.795）
     - 實際上同時改了三件事
  3. **norm 組被多給了 lr：**
     - K8 讓 norm 組的平均 lr 變成 ×1.34
     - CA/CB/CC（×0.5 +0.68%、×2 +0.49%、×4 +0.95%）顯示 norm lr 已經在最佳點附近
     - 依這條曲線的曲率，×1.34 約 +0.1%，會吃掉 K8 預期收益的一半左右
     - 最終 norm 也是控制輸出溫度的旋鈕
- **輸入端的論點（少見 token 的列只在出現時有梯度）：** 在 tied 下只對輸入端成立，而輸入端只占這些列梯度的一部分
- **判決：**
  - 機制部分成立
  - 1B 測試，優先度低於 K1/K3
  - 要測的話改成「只有 embedding 衰減 40–60%，norm 維持 80%」

### 4.2 K9：β1 ≈ β2
- **機制（Secret Sauce）：**
  - β1 = β2 時，m/√v ≈ μ/√(μ² + σ²) ∈ [−1, 1]，是乾淨的訊噪比縮放
  - β1 0.9 ≪ β2 0.9873 時，m 的窗口（10 步）比 v 短（約 79 步），更新較吵，而且可能大於 1
  - 這是逐元素的性質，跟參數是輸入層還是輸出層無關，所以 tied 不會讓機制失效
- **但要注意：**
  - 輸入端少見 token 的梯度是一陣一陣的。β1 0.975 會把一次爆發攤到約 40 步，總位移差不多（模擬估算：β1 0.9 約 9.4、0.975 約 11.9，以 lr 計）
  - EMA-Nesterov 還有 100 步的前瞻，動量會疊加
    - Muon 的 BD（momentum 0.98）+0.88%，說明這個配方對「更慢的動量」敏感
  - 證據來自整個模型都用 Adam；只用在 21% 的參數上，預期 ≤0.1%
- **判決：**
  - 機制部分成立
  - 有空位才做 1B，否則放棄；不要未經測試用在 6B

## 5. K7：EMA-Nesterov 提早開啟、ramp

### 5.1 開啟時跳升的來源（依實際公式）
- **遞迴：**
  - p_{t+1} = p_t + step_t + β_t·m_t
  - m_t = (γ + (1−γ)β_{t−1})·m_{t−1} + (1−γ)·step_t
  - step = −lr·(update + wd·p)
- **窗口外 β = 0 時，m 仍然在更新：** 開啟時 m 已經是暖好的 100 步 EMA
- **開啟的那一步：**
  - 權重只多移了 β·m ≈ 0.6 步，**不是權重的不連續**
  - 持續方向的每步位移立刻變成 1.6 倍，約 250 步後到 2.5 倍
  - 模擬：0 步 1.60、100 步 1.90、250 步 2.17、500 步 2.36，跟 T4 一致
- **所以跳升是「慢分量的等效 lr 突然 ×1.6–2.5」的反應，有兩個成分：**
  1. 低曲率方向上，雜訊驅動的偏移變大（T4 說的「山壁」）
  2. wd 的收縮也被放大，在 stable 段等效 τ 只剩 1/2.5（第 3.3 節）。AN 顯示 τ 變短在 stable 段會變差、衰減後變好
- **兩者都會隨 lr·β 下降而消失**，跟「追回的時間跟著比例走」相符

### 5.2 提早開啟
- **好處：**
  - 放大作用在學習最快的那段，持續分量大，前進更多
  - 只放大慢於約 100 步的分量，高曲率的快速震盪不會被放大，所以發散風險有限（同意 T4）
- **代價：**
  - 早期的「慢分量」裡也有早期的快速變化
  - 等效 τ 再縮短（6B ×1.64 → ×1.90），跟 K4 重疊
- **ramp：**
  - 500 步的 ramp 讓開啟時從 1.0 慢慢升（500 步時 2.04）
  - 總收縮從 2.60 降到 2.42 e-fold，最終值的影響應在 ±0.05%（同意 T4）
  - 不值得單獨一個位置

### 5.3 判決
- **機制：成立**
- **1B 測試，優先度低**
- 若 6B 同時採用 K4，要把 ×1.16 的額外收縮算進 τ
- ramp 不必做

## 6. K13：上下文窗口由短到長

### 6.1 數學上代表什麼
- 學生在位置 t 只看到窗口 c（完整前文 x 的子集）
  - 在期望 loss 下，學生的最佳解是 E[q | c]
- **資料部分：** E[e_y | c] = p_data(· | c)，正確
- **老師部分：**
  - 若老師對完整前文是校準的，E[p_T(·|x) | c] = p_data(·|c)（全機率），所以完整前文的老師仍然是窗口條件分布的**無偏**估計
  - 這是「特權資訊」式的蒸餾，不是矛盾
- **變異數：**
  - Var(e_y | c) = E[Var(e_y | x) | c] + Var(p(·|x) | c)
  - 老師 target 只剩第二項，所以仍然比 CE 小
  - 但縮減幅度比完整前文時小：老師在窗口外看到的資訊，變成學生眼中的 target 雜訊
- **偏差（新的問題）：**
  - V0 的 tail 縮小倍數是 1−α·m(x)，m 是完整前文下（較尖銳）老師的 top-32 質量
  - 窗口條件的真實分布比較寬，它在「完整前文 top-32 以外」的質量更多，但 V0 把這些都壓到 (1−αm) 倍
  - 所以**被切斷的位置，V0 的 tail 偏差會放大**
  - K1 在期望上消除這個偏差
- **其他：**
  - RoPE 是相對位置，position_ids 不重設沒問題（同意 T6）
  - 被切開的區塊沒有 BOS 可以當 attention sink，前期有不一致
- **結論：** 「老師與學生的上下文不一致」本身在期望上無害，代價是 KD 的變異數縮減變小，以及 V0 的 tail 偏差變大

### 6.2 判決
- **機制：** KD 的部分在數學上可以接受，但收益的先驗（doc masking 已經縮短平均窗口、5 TPP）很低
- **截止前放棄**
- 若之後要做，先有 K1，否則 V0 的偏差會放大

## 7. K2：事後溫度

### 7.1 等效性
- **HF Llama 的計算：** logits = lm_head(norm(h))，norm(h) = g ⊙ h/rms(h)
  - lm_head 沒有 bias，後面也沒有 softcap
  - 所以 g → g/T 會讓 logits 剛好變成 logits/T，**精確等價**
- **輸入端：** `model.model.norm` 只用在最後一層之後；tied 的是 `embed_tokens` 和 `lm_head`，norm 權重不在裡面
  - 改 g 不影響 input 端
- **bf16：** g/T 重新捨入成 bf16，每個元素的相對誤差 ≤ 2^−9，跟原本 g 的捨入同級，可以忽略
  - 但 T* 要用 OJ 的 bf16 流程來找

### 7.2 能修多少
- 全域溫度是 V0 偏差的不完全修正
  - V0 的偏差包含「head 對 tail」的質量轉移（`k1_d.py` 裡學生的 top-32 加成 b ≈ 1.1–1.5）
  - 溫度只能修一部分：T1a 的 sim2 在理想學生下修 57%
- T6 的玩具是**每個位置各自找最佳 T**，所以「約補回一半」是上界，不是單一 c 能做到的

### 7.3 判決
- **機制：成立**
- **先量測，不需要訓練**
  - 量 BU、CH、CJ、CL 的 T*
  - 預期：BU ≈ 1；KD 的 T* > 1，而且隨 α 上升
  - 這同時是 K1 前提最便宜的檢驗
- T* > 1、在 judge 以外的資料上確認有收益、你也確認合規時，可以直接套到 6B 的最終權重
- 若 6B 採用 K1，T* 應該接近 1

## 8. D 節「不建議」的檢查
- **錯誤排除（理由不成立）：** 「最後把 α 降到 0：CD 已顯示 α 0.5 明顯差」
  - 見第 2.4 節：CD 是整段固定 α，不能回答這個問題
  - 理論預測 α* → 0
  - 建議：K3 若贏，第二支可以把 α_end 降到 0.5（T1b 也這樣建議）
- **部分有疑問：** 「γ 改成以整段比例計」
  - 改成整段比例在 6B 是 γ 0.9983，排除是對的
  - 但 EMA-Nesterov 原論文顯示最佳 γ 隨總步數上升（2500 → 5000 步時 0.99 → 0.995）
  - 機制上，快速震盪的時間尺度以步數計約 ∝ 1/(lr·曲率)；6B 的 lr ×0.8，時間尺度會拉長約 1.25 倍，對應 γ ≈ 0.992
  - CG（0.997）只輸 0.09%，也沒排除這個小調整
  - 不值得在截止前花一個位置，但「γ 一律以步數計固定 0.99」不是有證據的最佳值
- **其他項目：** 從機制上看都排除得合理
  - top-32 重新正規化：偏差方向跟 V0 一樣而且更糟
  - ghost tail：tail 的形狀沒有監督
  - reverse KL：mode-seeking 跟 ppl 方向相反
  - schedule-free、衰減段權重平均：衰減到 0 時已經在做平均
  - z-loss、grad clip：Muon 對尺度不敏感

## 9. F 節的回答

1. **K1 的推導和程式草圖是否正確？**
   - 正確。期望值、Σq、梯度 (Σq)·softmax − q 都驗算過，數值上跟 autograd 一致（差 < 1e-16）
   - 小修正：
     - 無偏的條件只影響正規化 Z(x)，tail = p_data 不需要條件
     - Σq 的範圍是 [1−α+αm, 1+αm]，不是 0.8–1.8
     - `alpha * tail` 會被提升成 float32，實際程式沒問題
   - T1a 沒強調的代價：每個位置的標籤雜訊變成 2–3 倍（第 1.2 節）
2. **K1 和 K3 該分開測，還是疊在同一支？**
   - 機制上兩者解釋同一個現象（衰減段 α 1.0 落後），K1 會縮小 K3 的空間
   - 建議同一批平行跑 2×2：K1、K3、K1+K3，都對照 CJ
   - 只有兩個位置時選 K1 和 K1+K3
   - 不建議只跑 K1+K3 一支：贏了也不知道該把哪個帶到 6B，而且 α 的設定依賴 K1
3. **K4（τ 0.2）的證據夠不夠強，能不能不經 3B 直接用？**
   - 方向夠強，幅度不夠
   - EMA-Nesterov 的修正（第 3.3 節）讓 1B 的基準從 0.28 變成 0.39–0.48，0.2 相當於 b ≈ 0.45，偏激進
   - 不經 3B 的話，用 0.22–0.25 比 0.2 安全；有 3B 位置就跑 E1
   - 不要跟 K7 同時未經測試就改
4. **10-18 只有一批 1B 加一支 3B 時，選哪幾支？**
   - **1B（依優先順序）：**
     1. K1
     2. K1+K3
     3. K3
     4. K1 + α 1.0 固定（T1a C3，看 K1 之後 α 往哪移）
     5. 還有位置才放 K7（8% 開啟）或 K8（只動 embedding）
   - **不訓練的量測：** K2 的 T* 量測（約 1 GPU-h）跟 1B 同時做，它是 K1 的前導診斷
   - **3B：** E1（τ 0.22），因為 τ 是 6B「收益 × 不確定性」最大的一項（Power Lines 對的話 τ 0.39 的懲罰約 1%）
     - K1 的 6B 轉移在理論上不會比 1B 差，用 1B 的證據就夠
5. **哪些可以直接放進 6B、不用測？**
   - **K2：** 量到 T* > 1，而且你確認合規
   - **K3′：** 不做 α 排程時用 α 0.85
     - 若採用 K1 則用 0.85–0.9，不要再降
   - **K12：** 批次維持 131k
   - **K6：** 衰減 0.85，差異很小，方向合理
   - **K5：** Muon lr 1.05e-3 可以跟 K4 一起改，差異 ±0.1%
   - **K10：** 純系統改動，CPU 位元一致測過才用
