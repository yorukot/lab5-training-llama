  - 單趟訓練的文獻一致指向「tokens 越多，最佳 τ 越小」

  - 不降到 0.2 以下
  - 這是四個視角都同意的方向；3B 的 E1 可以校正
- **6B 推估往上修：**
  - CM（4.5B）= 11.97，基準線正在飽和
  - 現在的配方預估 6B in-training 約 11.55（11.45–11.70），OJ 約 11.69

- **其他十幾個候選：** 證據弱、收益在雜訊內，或跟現有配方重複，截止前都不做

## 7. 明確不建議（有證據）
- **蒸餾：**
  - 換 loss 形式（RKL、skew、TVD、AKL、MSE）：預訓練時 forward KL 一致最好；Busbridge 測到 RKL 差 0.28 nats
  - tail 均勻分配、tail 依學生分配、top-32 重新正規化：都比現在差
  - 丟 token（Rho-1 類）：OJ 評全部 token
  - α 從 0 暖身：跟我們 CI 的數據相反
  - 「最後把 α 降到 0」：沒測過，低優先；原本的排除理由不成立
- **排程與權重平均：**
  - 長衰減配 1-sqrt：待辦清單的「20% 1-sqrt」建議移除
  - schedule-free；γ 改成以整段比例計
  - 權重平均：限定在「學到 0 的線性衰減、事後對 checkpoint 平均」這個範圍內，收益 ≤0.12%。SODA（NeurIPS 2026）把 wd 看成權重平均的做法，在 124M 上贏過調好的 Muon 約 0.015 nats，不在這個排除範圍內，但截止前不做
- **批次：** 6B 改 262k、批次漸增
- **優化器：** AdEMAMix、外層 Nesterov（跟 EMA-Nesterov 重疊）、AdaMuon、MARS、Muon 上的 cautious 遮罩、Shampoo / SOAP / Kron、embedding 改用 Muon、Hyperball
- **截止前不做：** K3（α 排程）、K7（EMA 提早開啟，會跟 τ 重疊）、K8 和 K9（AdamW 組；證據降級，1B 預期 ≤0.3%）、K13（SkyLadder）、K10（NS 分散到多卡）
- **精度：** 最後一段改純 bf16、更好的捨入。依程式分析**估計** bf16 只佔 OJ 與 in-training 差距的約一成；這是估計，還沒量測
