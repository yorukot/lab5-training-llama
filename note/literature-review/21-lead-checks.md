## 1. K1 的前提：現在的 target 實際給 tail 多少權重（D0 診斷）
- 樣本：4 個快取 shard（頭、1/3、2/3、尾），每個取前 24 列，共 785,759 個位置；已排除跨文件邊界的預測
- 結果：

| 項目 | 數值 |
|---|---|
| P(答案在老師 top-32 外) | 0.0746 |
| E[m]（top-32 總機率） | 0.9268；E[1−m] = 0.0732，老師的 tail 總量對資料是校準的 |
| E[m \| 答案在外] | 0.7321 |
| E[m \| 答案在內] | 0.9425 |
| 答案在外時，現在給答案的權重 E[1 − αm \| 外]：α 0.8 / 0.9 / 1.0 | **0.414 / 0.341 / 0.268**（無偏是 1.0） |

- **解讀：**
  - 偏差存在：tail 被低估 2.4 倍（α 0.8）到 2.9 倍（α 0.9）
  - 比 T1a 用 m=0.9 推的 0.28 倍溫和，因為答案落在外面時 m 只有 0.73
  - 粗估理想學生的額外 CE：
    - α 0.8 約 0.02 nats，α 0.9 約 0.03 nats
    - 算法：tail 項 0.0746·ln(1/0.41) 減去 head 被灌水的項；位置之間的異質性會讓實際值更大
  - 用理論派估的實現比例 15–35%，K1 在 1B 約 −0.4% 到 −1%，跟 T1a 的中位 −0.5% 一致
  - 結論：**K1 的前提通過驗證，維持第一優先**
  - 學生實際實現了多少，要等 K2（量最佳溫度）或 K1 的 1B 測試才知道

## 3. 初始權重投影：直接量 wd 被放大了多少（R1 建議）
- **方法：**
  - 照 `training.py` 的做法，用 `set_seed(42)` 加 `from_config` 重建初始權重 W_0
  - 算每組的 r = ⟨W_T, W_0⟩ / ⟨W_0, W_0⟩，也就是初始成分還剩多少
  - 只有 wd 會讓初始成分衰減，更新大致跟 W_0 無關，所以 −ln r ≈ 整段的 wd 收縮量（e-fold）
- **結果：**

| run | EMA | attn | mlp | embedding |
|---|---|---|---|---|
| BU（1B） | 無 | 0.1876 | 0.2469 | 0.2047 |
| CF（1B） | 有 | 0.1008 | 0.1283 | 0.1130 |
| CG（1B，γ 0.997） | 有 | 0.0870 | 0.1212 | 0.0958 |
| CH（1B，KD） | 無 | 0.1809 | 0.2522 | 0.2044 |
| CJ（1B，KD） | 有 | 0.1048 | 0.1394 | 0.1174 |
| BY（3B） | 無 | 0.2101 | 0.2959 | 0.2332 |
| CL（3B，KD） | 有 | 0.1498 | 0.2015 | 0.1775 |

- **檢驗 1，初始權重重建對了嗎：** 對
  - 沒有 EMA 的 run，r ≈ 0.18–0.30，跟理論的 exp(−1.53) ≈ 0.22 一致
  - 如果重建錯了，r 會接近 0
- **檢驗 2，放大倍數（有 EMA 與沒 EMA 的 e-fold 比值）：**
  - 1B：BU→CF ×1.37–1.47，CH→CJ ×1.32–1.43
  - 3B：BY→CL ×1.19–1.32
- **結論：**
  - wd 確實被 EMA-Nesterov 放大了，但只有理論穩態值（×1.64–1.70）的一部分，而且規模越大越小
  - CL 的有效 τ 約 0.39 / 1.25 ≈ 0.31，不是 0.24；6B 的放大可能是 ×1.2 左右
- **對 K4 的影響：**
  - 「重複下藥」的疑慮比四個視角估的小
  - 名目 τ 0.25 在 6B 相當於有效約 0.2，正好是 T3a 原本建議的值
  - 所以維持 6B 名目 τ **0.25**（範圍 0.22–0.27），E1 仍測 0.22
- **注意：** 更新本身也可能有沿著 W_0 的成分，有沒有 EMA 時不一定一樣，所以這是近似量測。CG（γ 0.997）的放大更多，符合 EMA 越長、放大越多的預期
